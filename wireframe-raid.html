Mode Difference Legend — RAID vs DUNGEON

Accent Color

RAID mode uses #e8a820 gold for active states, borders, and highlights. DUNGEON mode switches these to #40b8e8 blue.

Mode Toggle

Filter bar right side. RAID active = gold pill. DUNGEON active = blue pill. Inactive mode is muted --text-muted. Toggling changes accent color system-wide and filters History/Trends data.

Session Label

RAID: "Pull #N" (e.g. Pull #47). DUNGEON: "Run #N" (e.g. Run #12). This label appears in the titlebar badge, encounter header, summary bars, and history rows.

INT% vs INTERRUPT Label

RAID: stat counter labeled INT% in gold. DUNGEON: stat counter labeled INTERRUPT in blue — more prominent, reflects M+ priority.

Performance: Rank vs Time Lost

RAID Performance table last column = Rank (pull history percentile). DUNGEON = Time Lost (seconds lost to death, downtime, failed CC).

Trends Metric Order

RAID: Deaths (1st) → Interrupt Rate (2nd) → Group DPS (3rd) → CC Coverage (4th). DUNGEON: Interrupt Rate (1st, most critical for keys) → Deaths (2nd) → DPS (3rd) → CC (4th).

History Filter

History tab is filtered by active mode. RAID shows only raid encounters (boss pulls with pull numbers, Mythic difficulty). DUNGEON shows only dungeon runs (encounters with Run #, key level context).

History Interrupt Column

RAID History: column header Int % in standard gold accent. DUNGEON History: column header Interrupt in blue — visually distinguished to reinforce M+ priority.
