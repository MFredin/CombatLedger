CombatLedger Design Reference — DUNGEON Mode

This wireframe documents the full UI layout for CombatLedger in DUNGEON mode. All six tab panels are shown stacked vertically below the shared frame chrome. The History tab is active in the tab bar (blue underline). Blue replaces gold as the primary accent throughout — interrupt tracking is elevated as the primary M+ metric. Use this document alongside the RAID wireframe to understand all mode-specific differences.

Mode Difference Legend — DUNGEON vs RAID

Accent Color

DUNGEON mode uses #40b8e8 blue for all active states, tab underlines, borders, stat highlights, and column headers. RAID mode uses #e8a820 gold. The logo hex also changes color to match the active mode.

Mode Toggle

Filter bar right side. DUNGEON active = blue pill on the right side. RAID = muted on left side. Toggling reloads data source and swaps the accent color system-wide, including table headers, banner borders, tab underlines, and stat values.

Session Label: Run #N

DUNGEON: "Run #12" used in the titlebar badge, encounter card subtitle, summary bars, and history rows. RAID uses "Pull #47". This is a persistent label difference across all tabs when in dungeon mode.

INTERRUPT stat — prominent blue

Overview stat counter: DUNGEON labels it INTERRUPT (not INT%) and renders the value larger in blue with a blue label. In RAID the same stat is smaller, gold, labeled INT%. This elevates interrupt tracking as the M+ priority metric.

Performance: Time Lost column

DUNGEON Performance table last column is Time Lost — shows seconds added to the run timer per player (death penalty + downtime). RAID last column is Rank showing pull history percentile. All other columns are identical.

Trends Metric Order

DUNGEON: Interrupt Rate % (1st, blue, labeled M+ Priority) → Deaths (2nd) → Group DPS (3rd) → CC Coverage (4th). RAID: Deaths (1st) → Interrupt Rate (2nd) → Group DPS (3rd) → CC Coverage (4th). First metric reflects mode priority.

History Filter + Column

History tab shows only dungeon runs — raid encounters are hidden. The Interrupt column header is rendered in blue (not gold). The Difficulty column shows key level badges (M+9, M+10, M+11, M+12). "Depl" is used as the wipe result label for depleted keys.

Affix Context

Dungeon Overview and CC Coverage panels display active affix badges (e.g. Fortified, Bursting). An affix context callout in CC Coverage explains how the current affixes make CC coverage directly relevant to survivability.

RAID Mode Summary
  • Gold accent (#e8a820) throughout
  • Session label: "Pull #N"
  • INT% stat — small, gold
  • Performance: Rank column (percentile)
  • Trends first metric: Deaths
  • History: boss encounters, Mythic difficulty
  • History result: Kill / Wipe
  • No affix context shown
DUNGEON Mode Summary
  • Blue accent (#40b8e8) throughout
  • Session label: "Run #N"
  • INTERRUPT stat — large, blue, prominent
  • Performance: Time Lost column (seconds)
  • Trends first metric: Interrupt Rate %
  • History: dungeon encounters, key level badges
  • History result: Kill / Depl (depleted)
  • Affix badges and context callout shown
